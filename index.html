GUÍA RÁPIDA

Cómo usar tu Pokédex

1. Marca tus Pokémon

Toca o haz clic en una tarjeta para alternar entre Conseguido y Pendiente. El progreso se guarda automáticamente en este navegador.

2. Busca y filtra

Busca por nombre o número nacional. La búsqueda ignora mayúsculas y acentos. Puedes combinarla con el filtro de estado.

3. Corrige un toque

Dentro de una generación, usa Deshacer para revertir el último cambio. Las acciones masivas y el reinicio solicitan confirmación.

4. Exporta tu respaldo

En la pantalla principal pulsa Respaldo y luego Exportar. Se descargará un archivo JSON con tu progreso. Guárdalo en un lugar seguro.

5. Importa o traslada tu colección

En el otro dispositivo abre la Pokédex, pulsa Respaldo e Importar y selecciona el archivo. Usa Combinar para conservar las marcas de ambos dispositivos o Reemplazar para usar exactamente el archivo.

6. Ver y quitar conseguidos

En el inicio, Ya conseguidos muestra los 12 más recientes. Pulsa Ver todos y administrar para abrir la lista completa: busca, filtra por generación, marca varios con la casilla y usa Desmarcar seleccionados. También puedes desmarcar todos de una vez; ambas acciones piden confirmación y se pueden deshacer.

7. Dónde obtenerlo

Cada tarjeta tiene el botón Dónde obtenerlo. Al abrirlo, la tarjeta ocupa toda la fila y muestra un bloque por juego. Las filas «Revisado a mano» se comprobaron una por una; las «importadas» vienen de una fuente externa guardada en tu equipo y están por verificar.

8. Música

La barra inferior reproduce la música de la carpeta musica. Pulsa ▶ para empezar; usa ⏮ y ⏭ para cambiar de pista, −10 s y +10 s para moverte, ⇄ para orden aleatorio y ↻ para repetir. El botón ♪ Lista permite buscar y elegir pistas. Si agregas música nueva, ejecuta ACTUALIZAR_MUSICA.cmd.

Importante: cada navegador guarda su propio progreso. Borrar los datos del navegador puede eliminarlo. Exporta respaldos periódicos. Para trasladar la colección, puedes mover el archivo mediante Google Drive, OneDrive o Dropbox.
